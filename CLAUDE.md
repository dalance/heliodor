# Heliodor

This file is intentionally a stub.

The authoritative development conventions — heliodor phase branch policy,
benchmark methodology, Veryl simulator optimization workflow, command
conventions — live in **`.claude/CLAUDE.md`** (untracked, project-local).
Claude Code auto-loads both this file and `.claude/CLAUDE.md` into context,
so the `.claude/` version is effective even though this file is minimal.

Keeping this file as a stub (identical across all `phase*` branches) lets
phase switches happen cleanly without `CLAUDE.md` becoming a working-tree
modification each time.
